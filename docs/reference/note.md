## bottega note list

**Synopsis:** `bottega note list [text] [--project <X>] [--stale] [--session <ID>] [--actionable] [--kept] [--json] [--new]`

list notes from the local record

### Options

- `--project <X>`: limit notes to this project
- `--stale`: include stale notes
- `--session <ID>`: limit notes to this session (default: )
- `--actionable`: list notes ready for disposition
- `--kept`: list notes acknowledged by the selected sessions
- `--json`: write the note rows as JSON
- `--new`: treat list as note text and show the filing remedy

### Related

- [bottega note](./note.md#bottega-note)

## bottega note new

**Synopsis:** `bottega note new <text> [--project <name>] [--same-as <reference>] [--new] [--area <area>] [--anchor-json <json>] [--json]`

file a new observation or another sighting

### Options

- `--project <name>`: file the note for this project
- `--same-as <reference>`: record a sighting of this existing note
- `--new`: file a distinct note despite possible duplicates
- `--area <area>`: classify the note under this area
- `--anchor-json <json>`: use this explicit provenance anchor
- `--json`: write the filed note and candidates as JSON

- [bottega note](./note.md#bottega-note)
