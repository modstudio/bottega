**Synopsis:** `bottega doc set [slug] [--scope <value>] [--subject <value>] [--user] [--cwd <value>] [--title <value>] [--file <value>] [--reason <value>] [--author <value>] [--expect <revision>] [--delivery <value>] [--audience <value>] [--parent <slug>] [--no-parent] [--position <value>] [--featured] [--no-featured] [--status <value>] [--kind <value>] [--replacement <slug>] [--form <value>] [--no-form] [--article-subject <value>] [--no-article-subject] [--related-subject <value>] [--no-related-subjects] [--source-file <value>] [--no-source-files] [--checked-at <commit>] [--no-checked-at] [--summary <text>] [--no-summary] [--force-inject <value>] [--json]`

create or revise a document

### Options

- `--scope <value>`: select the document scope
- `--subject <value>`: select the document subject
- `--user`: address the signed-in user document
- `--cwd <value>`: use this working directory
- `--title <value>`: set the title
- `--file <value>`: read the body from a file
- `--reason <value>`: record the reason for the change
- `--author <value>`: record the revision author
- `--expect <revision>`: require the current revision
- `--delivery <value>`: set demand or inject delivery
- `--audience <value>`: filter or set document audiences
- `--parent <slug>`: set the parent article slug
- `--no-parent`: clear the parent article slug
- `--position <value>`: set the article position
- `--featured`: mark the article as featured
- `--no-featured`: mark the article as not featured
- `--status <value>`: filter or set document status
- `--kind <value>`: filter or set document kind
- `--replacement <slug>`: name the replacement document
- `--form <value>`: set the article form
- `--no-form`: clear the article form
- `--article-subject <value>`: filter or set the article subject
- `--no-article-subject`: clear the article subject
- `--related-subject <value>`: add a related subject name or id
- `--no-related-subjects`: clear all related subjects
- `--source-file <value>`: add a repository-relative source path; with --no-source-files, replace all
- `--no-source-files`: clear all source files; with --source-file, replace with those paths
- `--checked-at <commit>`: set the commit checked by this article
- `--no-checked-at`: clear the checked commit
- `--summary <text>`: set the written summary
- `--no-summary`: clear the written summary
- `--force-inject <value>`: give the reason for overriding inject policy
- `--json`: print JSON output
