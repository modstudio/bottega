## bottega dashboard check

**Synopsis:** `bottega dashboard check [--port <N>] [--down] [--help]`

### Options

- `--port <N>`: port to inspect for a recorded dashboard
- `--down`: require the recorded dashboard to be stopped
- `-h, --help`: display help for command
