## bottega session adopt

**Synopsis:** `bottega session adopt <session> [--reason <text>] [--cut-off] [--json]`

take over another session's run chains

### Options

- `--reason <text>`: record why this session is taking ownership
- `--cut-off`: adopt when every owner process is gone but last_seen is recent
- `--json`: write the adoption report as JSON

## bottega session report

**Synopsis:** `bottega session report [--session <id>] [--all] [--since <date>] [--until <date>] [--compare <since>] [--json]`

measure task-cursor attribution and residue over a session window

Unanswered questions use the durable open-question predicate: neither answered nor closed. This differs from question inbox, which lists its needs-attention subset. Past-window unscored runs and open cursors are marked approximate.

### Options

- `--session <id>`: select one session; repeat to select more
- `--all`: select every recorded session
- `--since <date>`: start the current window at this ISO date
- `--until <date>`: end the current window at this ISO date
- `--compare <since>..<until>`: compare against this second window
- `--json`: write the report as JSON
